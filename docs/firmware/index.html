Mimic X Firmware Update

Mimic X (CH32X035) のファームウェアを Web ブラウザから書き込むページです。 プロジェクト: MimicX-firmware

準備

このページを開いた状態で、CH32X035 の BOOT ボタンを押しながら USB ケーブルを接続する
すぐにこのページの「デバイスに接続」ボタンを押す（BOOT モードは無通信のまま約 5 秒経過すると通常起動に抜けてしまうため、ページを開いてから USB を挿してください）
「QinHeng Electronics 製のデバイス」(または「WinChipHead 製の不明なデバイス」) を選択する
基板に合うバリアントとバージョンを選択して「書き込み」を押す
書き込み完了後、USB ケーブルを抜き差しして通常モードで起動する
Chromium 系ブラウザ（Chrome, Edge）が必要です。Safari / Firefox は WebUSB に対応していません。
BOOT モード (内蔵 USB DFU ブートローダー) は、ホストから ISP コマンドを受信しないまま約 5 秒経過すると自動的に通常起動へ抜けます。先にこのページを開いてから USB を接続し、すぐに「デバイスに接続」を押してください。間に合わなかった場合は、USB を一度抜いて BOOT ボタンを押しながら挿し直してやり直してください。
Windows をお使いの方へ: CH32X035 を BOOT モードで認識させるには、事前に WinUSB ドライバを手動でインストールしておく必要があります。手順は WinUSB ドライバのインストール手順 を参照してください。
