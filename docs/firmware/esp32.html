Mimic X 無線版 (ESP32 / XIAO C6) Firmware Update

Mimic X ワイヤレスアダプタ (ESP32 系 + CH32X035 の 2 チップ構成) の 無線側ファームウェアを Web ブラウザから書き込むページです。 ESP32-WROOM-32 / Seeed XIAO ESP32-C6 / XIAO ESP32-C3 に対応し、接続したボードを自動判別して対応イメージを書き込みます。 無線ファームは対応する CH32 ファームを内包しており、起動時に CH32 を自動同期します。 プロジェクト: MimicX-firmware
CH32 単体 (USB 直結版) の書き込みは こちら (WebUSB フラッシャー)。

準備

ボードを USB ケーブルで PC に接続する (BOOT 操作は不要。esptool が自動でブートローダへ入れます)
基板に合うバリアントとバージョンを選択する
「CONNECT」ボタンを押し、シリアルポートを選択する (ESP32 は CP210x / CH340 等、XIAO C6 は USB シリアル)
「INSTALL」を押して書き込む (接続チップを自動判別。フラッシュ全体を上書きします)
Web Serial 対応の Chromium 系ブラウザ (Chrome / Edge) が必要です。Safari / Firefox は非対応です。
これは 無線版 (ESP32 / XIAO ESP32-C6 / XIAO ESP32-C3 / XIAO ESP32-S3) 用です。CH32 単体 (USB 直結) のアダプタには使えません (その場合は CH32 用フラッシャー を使用)。
⚠ XIAO ESP32-C3 / C6 など内蔵USB (Serial/JTAG) の機種: 書き込み完了 (100%) の 直後にブラウザがクラッシュすることがあります。これは書き込み後のリセットで USB デバイスが 再列挙する際のブラウザ側の不具合で、書き込み自体は成功しています (挿し直せば 新ファームで起動します)。USB-UART ブリッジ搭載の ESP32 DevBoard では発生しません。気になる場合は idf.py flash でのネイティブ書き込みをご利用ください。
⚠ XIAO ESP32-S3: 書き込み完了後、ROM ダウンロードモードに残って USB-MIDI デバイスが現れないことがあります。RESET ボタンを一度押す (または USB を挿し直す) と "Mimic X (Bridge)" として認識されます。
ご使用の Mimic X ワイヤレスアダプタの基板に合わせて選択してください。
⚠️ 書き込みが終わったら、念のため USB ケーブルを一度抜き差しして ください。 書き込みの前後でアダプタは短時間に何度も USB を切り替えます。書き込み前に 入っていたファームウェアが古い場合、このとき OS 側に古い接続情報が残り、 「デバイスは見えているのに一切応答しない」状態になることがあります (macOS で確認)。抜き差しすれば確実に復旧します。書き込み後にアプリから 認識できない / 反応がない場合も、まず抜き差しをお試しください。
⚠️ 書き込みダイアログで「Erase device」を選ぶと、BLE の ペアリング情報 (ボンド) も消去されます。ペアリング済みの Windows からは 接続時に即切断が繰り返されるようになるため、通常の更新では erase を 選ばないでください。誤って消してしまった場合、アプリ v1.6.2 以降は 自動で再ペアリングして復旧します (それ以前のアプリでは Windows の [設定] > [Bluetooth とデバイス] から MimicX を削除して再接続して ください)。macOS / iOS / Android はペアリングを使わないため影響ありません。
バリアントとバージョンを選択してください
