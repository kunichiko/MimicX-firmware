Mimic X 無線版 (ESP32 / XIAO C6) Firmware Update

Mimic X ワイヤレスアダプタ (ESP32 系 + CH32X035 の 2 チップ構成) の 無線側ファームウェアを Web ブラウザから書き込むページです。 ESP32-WROOM-32 と Seeed XIAO ESP32-C6 の両対応で、 接続したボードを自動判別して対応イメージを書き込みます。 無線ファームは対応する CH32 ファームを内包しており、起動時に CH32 を自動同期します。 プロジェクト: MimicX-firmware
CH32 単体 (USB 直結版) の書き込みは こちら (WebUSB フラッシャー)。

準備

ボードを USB ケーブルで PC に接続する (BOOT 操作は不要。esptool が自動でブートローダへ入れます)
基板に合うバリアントとバージョンを選択する
「CONNECT」ボタンを押し、シリアルポートを選択する (ESP32 は CP210x / CH340 等、XIAO C6 は USB シリアル)
「INSTALL」を押して書き込む (接続チップを自動判別。フラッシュ全体を上書きします)
Web Serial 対応の Chromium 系ブラウザ (Chrome / Edge) が必要です。Safari / Firefox は非対応です。
これは 無線版 (ESP32 / XIAO ESP32-C6) 用です。CH32 単体 (USB 直結) の アダプタには使えません (その場合は CH32 用フラッシャー を使用)。
ご使用の Mimic X ワイヤレスアダプタの基板に合わせて選択してください。
